Token Saving Techniques

CLI-focused techniques for Claude Code, Cursor Agent (agent), Codex CLI, and Gemini CLI. Output tokens cost 5× more than input across all Claude models (Opus 4.7 & 4.6: $5 in / $25 out; Sonnet 4.6: $3 / $15; Haiku 4.5: $1 / $5 per MTok). Thinking tokens bill as output. Codex and Gemini show 4×–8× asymmetry. Every technique here reduces one or both.

The Meta-Rule
Every token is re-read every turn. A 50-line rules file across a 20-turn session is read 20 times — 1,000 lines from one file. Context isn't cost-per-message, it's cost × conversation length. Keep it tight, clear often, persist decisions, use the cheapest mode that works.
