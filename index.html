Token Saving Techniques

CLI-focused techniques for Claude Code, Cursor Agent (agent), Codex CLI, and Gemini CLI. Output tokens cost 5× more than input across Claude models (Sonnet 4.6: $3/$15, Opus 4.8: $5/$25, Fable 5: $10/$50 per MTok). Thinking tokens bill as output. OpenAI shows 6–8× asymmetry (GPT-5.5: $5/$30). Gemini shows 6–8× (3.1 Pro: $2/$12). Every technique here reduces one or both.

The Meta-Rule
Every token is re-read every turn. A 50-line rules file across a 20-turn session is read 20 times — 1,000 lines from one file. Context isn't cost-per-message, it's cost × conversation length. Keep it tight, clear often, persist decisions, use the cheapest mode that works.
