Token Saving Techniques

CLI-focused techniques for Claude Code, Cursor Agent (agent), Codex CLI, and Gemini CLI. Output tokens cost 5–6× more than input (Sonnet 4.6: $3/$15, Opus 4.7: $5/$25, GPT-5.5: $5/$30 per MTok). Thinking tokens bill as output. ⚠ Opus 4.7’s new tokenizer produces up to 35% more tokens for the same text — effective costs rise even at the same rate card. Every technique here reduces one or both.

The Meta-Rule
Every token is re-read every turn. A 50-line rules file across a 20-turn session is read 20 times — 1,000 lines from one file. Context isn't cost-per-message, it's cost × conversation length. Keep it tight, clear often, persist decisions, use the cheapest mode that works.
